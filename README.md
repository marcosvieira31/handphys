# handphys

Laboratório virtual de física (circuitos) por realidade mista, para uso em sala de aula — **um app, uma porta de entrada, três telas**.

- **Plano completo:** [`docs/PLANO.md`](docs/PLANO.md)
- **Fase 0 — spikes:** [`docs/SPIKE.md`](docs/SPIKE.md)

## As telas do app

O app abre na **bancada** (a raiz) e cada aparelho da sala entra pela tela que lhe cabe:

| Tela | Onde roda | Endereço |
| --- | --- | --- |
| **Bancada** — montar o circuito | PC do professor / tablet | `/` (a casa; abre por padrão) |
| **Espelho** — projeção da sala | projetor / segunda aba | `/#/espelho` (ao vivo, sem edição) |
| **Sala** — o que é e como usar | qualquer lugar | `/#/ajuda` |
| **Cardboard** — bancada 3D estéreo | celular no visor | `cardboard.html` (página própria, de propósito) |
| Estante de spikes | equipe | `spikes/` (fora do produto) |

O circuito viaja num link `?c=` (base64url): o **Compartilhar** gera QR para os **três destinos** (PC, celular e projetor). `editor.html` e `mirror.html` continuam existindo como **redirecionamentos** — os QRs que já estão na sala caem na rota certa, com `?c=` e `?sala=` intactos. O **cardboard** mantém página própria de propósito: vanilla (zero React no celular) e com alarme de rede lenta no HTML clássico — a escola com Wi-Fi ruim é o público.

## Estrutura

```
index.html          → shell do app (src/main.tsx — telas por hash, import preguiçoso)
editor.html         → redirect → / (bancada; QR antigo com ?c=)
mirror.html         → redirect → /#/espelho (?c= e ?sala= preservados)
cardboard.html      → vista do celular (vanilla; src/cardboard/)
spikes/             → estante de desenvolvimento (hands, cardboard)
src/
  main.tsx rotas.ts Sala.tsx   → shell, rotas e tela de ajuda
  core/       → solver MNA, netlist, Kirchhoff, fluxo de corrente
  scene/      → bancada 3D (three.js)
  editor/     → a bancada (quadro 2D, trilhos, mãos, share, desafios, relatórios)
  mirror/     → espelho (protocolo, peer/WebRTC, follower)
  cardboard/  → viewer estéreo do celular
  hands/      → hand tracking (MediaPipe) — só da bancada
  spikes/     → os spikes 0.1/0.2
  styles/     → editor.css (app), espelho.css, sala.css, spike.css (spikes)
```

## Rodar

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # typecheck + build estático (saída em dist/)
npm test         # testes do solver (Vitest)
```

O `npm run dev` abre a **bancada**; as outras telas ficam em `#/espelho` (projeção) e `#/ajuda` (sala). `cardboard.html` é a vista do celular, testável direto no navegador.

## Deploy

Publicação automática no **GitHub Pages** a cada push em `main`
(<https://marcosvieira31.github.io/handphys/>) — o workflow
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) roda `npm test` +
`npm run build` antes de publicar.

- O `base` vem do `BASE_PATH`: o CI define `/handphys/` (subdiretório do Pages),
  dev e `preview` ficam na raiz.
- Para publicar em domínio raiz (ex.: Netlify), é só buildar **sem** `BASE_PATH`.
- Local: `npm run build && npm run preview` (build de produção servido em `:4173`).

- [x] Fase 4 (parcial) — **estação de Kirchhoff (leitura por nó)**: a 1ª lei apareceu na tela. [`src/core/kirchhoff.ts`](src/core/kirchhoff.ts) (`porNo`) reorganiza a MESMA leitura do solver por nó — cada junção lista seus **ramos com o sentido relativo àquele nó** (`entra`/`sai`; o mesmo ramo é "sai" num nó e "entra" no outro, porque a corrente anda de `netA` para `netB` quando `amps > 0`) e a conta `Σ(entram) − Σ(saem)`, verde quando fecha. A lei vale **por construção** (é o que o solver impõe), então o valor da estação é o aluno **ler e confirmar** — o Σ só flutua em ~1e-16 (`KCL_TOL`), nunca sai erro a corrigir. - [x] Fase 4 (parcial) — **estação RC: carga, descarga, τ e o osciloscópio**: o transitório que o motor já calculava virou bancada. O núcleo é [`src/core/rc.ts`](src/core/rc.ts) — `rcStation(doc, capId?)` devolve as **duas experiências** do mesmo circuito (`carga` e `descarga`, cada uma uma `RcCurve` com `v0`, `vinf`, `tau`, `window`, `t[]`, `v[]`, `i[]`), tudo **função pura do documento**: o espelho recalcula a MESMA curva do MESMO doc (a filosofia da estação de Kirchhoff). O par carga/descarga do livro **não existe com uma chave simples** (fonte—chave—R—C: abrir a chave não fecha laço; R ∥ C: a fonte ideal curto-circuita o R, τ = 0): quem resolve é a chave **comutadora de duas posições** da bancada de verdade, e a 2ª posição é `semFontes(doc)` — cada fonte vira uma chave fechada, isto é, um **fio**. O **τ é medido como o osciloscópio mede**: `medirTau` acha o cruzamento dos 63,2% (`TAU_FRACAO = 1 − e⁻¹`) **interpolado** entre as amostras que o abraçam, valendo subindo e descendo (o alvo está sempre entre v0 e vinf) e devolvendo `null` na reta parada. A escala do tempo é **descoberta**: ΣR é limite superior do R de Thévenin (R_th ≤ ΣR), então a janela começa em ΣR·C/64 e **dobra** até assentar (sobra ≤ 0,5%, com tetos de 40 dobras e 1e12 s), e o τ medido dispara a passada **fina** de 400 amostras em 4,5 τ — é ela que vai para a tela, e por isso o eixo do tempo cai sempre em "0 … ~4,5 τ". Recusas honestas em vez de curva inventada: sem capacitor não há estação; valor zero, capacitor direto na fonte ou circuito sem solução (montagem pela metade, matriz singular) dão `null` e a tela mostra a dica; sem fonte ela avisa que não há o que carregar.
